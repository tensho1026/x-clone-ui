## 📝 概要
このプロジェクトは、**X（旧 Twitter）のクローン UI** を開発するための Next.js アプリです。  
現在、開発途中であり、順次機能を追加予定です。

## 🔧 使用技術
- **フレームワーク:** Next.js (App Router)
- **言語:** TypeScript
- **スタイリング:** Tailwind CSS
- **UI コンポーネント:** ShadCN/UI
